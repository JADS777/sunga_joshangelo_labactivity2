# Lab Activity 2 - Student Management System

## How to run
1. cd into this folder
2. python3 main.py
3. Follow the menu (1-5)

## Data types used
- String: names, ID, middle initial
- List: skills
- Tuple: birthdate (month, day, year)
- Dictionary: students (main record store)
